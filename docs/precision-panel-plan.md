# 精密指标面板实施计划

目标：在原生 macOS 界面中提供清晰的概览、简短悬停说明和可返回的指标详情。视觉细节服务于数据含义，不增加持续运行的装饰动画或第二套采样状态。

1. **共享图形尺度**：趋势折线为 1.75 pt；经典容量条为 3 pt、卡片为 4 pt；主刻度和阈值标记弱化。概览一项一个主要图形，详情才显示完整轴与统计。
2. **解释与检视**：内存标题保持“内存”，百分比明确为压力估算；容量条按已用容量/总容量绘制。趋势图支持全绘图区悬停和键盘检视，使用真实采样时间与数值。
3. **详情与状态**：CPU、内存、磁盘、网络可进入详情。沿用共享导航、已有快照和最近 30 次历史；增加历史时间戳和上下行历史，保持同次采样对齐。详情支持返回用量、⌘[、Escape，页面尺寸保持顶部锚点；兼容旧系统经典弹出层。
4. **验证与交付**：验证历史对齐、滚动窗口、容量/压力语义、详情导航和尺寸恢复。运行完整单测和 Xcode Release 构建；用独立偏好检查中英文、经典/卡片、深浅色、长数值与键盘操作，记录实际覆盖及局限。

范围不包含温度、进程排行、新采样接口、长期历史、WebView 或 JavaScript 运行环境。

## 执行结果（2026-10-14）

四个阶段均已实施。图形、容量/压力文案、详情、历史对齐与键盘检视复用共享原生组件；README 中英文与开发指南已同步。用户要求测试不在前台显示应用后，已退出临时验证应用，后续采用后台测试及隐藏窗口离屏渲染。

具体测试结果与尚未覆盖的环境见 [维护验证记录](maintenance-validation.md#精密指标图形与详情2026-10-14)。
