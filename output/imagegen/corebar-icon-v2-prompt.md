# CoreBar 图标设计

使用内置 image_gen 生成。深石墨灰满版背景、绿色系统用量条；正方形，外缘四角为直角，背景不透明。原始 PNG 为同目录 corebar-icon-v2.png。

## 生成提示词

Use case: logo-brand.
Asset type: finished high-resolution macOS application icon master for CoreBar, a quiet local CPU, memory, disk, and network usage monitor.
Create ONE exceptionally refined modern minimalist app icon, square 1:1, preferably 2048 x 2048. This is the actual flat full-canvas icon artwork, not a presentation, mockup, grid, or device screenshot.
Concept: an unmistakable compact resource-utilization meter symbol: exactly THREE equally wide vertical rectangular meter tracks, identical overall height, aligned to a shared top and bottom, arranged with precise even gaps. Each track contains one simple solid rectangular active fill rising from the bottom, with differing NON-ascending levels: left about 48 percent, middle about 76 percent, right about 34 percent. Visible upper unfilled portions are a quiet lighter graphite. The active fills are a single clean Apple-like healthy green (#34C759), with only the subtlest natural tonal variation. The equal-height background tracks make these read as system capacity meters rather than a finance chart.
Style: disciplined Swiss geometric reduction meets native macOS utility-app polish. All edges are precise and straight, including the meter bars. Strong silhouette, understated and beautifully proportioned. Large central symbol occupies about 64 percent of the canvas width and 64 percent of its height, with balanced internal breathing room. No axes, tick marks, curves, waves, arrows, text, letters, chips, extra dots, or decorative components.
Background: an opaque deep neutral graphite field (#242626), absolutely edge-to-edge, with a nearly imperceptible soft tonal lift toward the upper left for depth. The application UI uses neutral system surfaces, sparse controls, and healthy green status accents; match this restrained design language. No glossy 3D objects, thick bevels, extrusion, grain, neon, colored glow, cast shadows, or cyan/blue/purple accents.
CRITICAL OUTPUT GEOMETRY: canvas is a true full square with FOUR SHARP 90-DEGREE OUTER CORNERS; opaque color reaches every pixel along all four edges. DO NOT put the icon inside a rounded-square or squircle tile. No corner mask, no transparency, no surrounding white page, no external margins, no border, no inset app-icon plate, and no shadow outside the artwork. Only the finished flat icon fills the entire image. Preserve legibility at 32px.
